# تشغيل Agrismart AI Assistant

صفحة المساعد تستخدم نموذجًا حقيقيًا عبر OpenAI Responses API. مفتاح الخدمة يبقى على الخادم ولا يصل إلى ملفات المتصفح.

## تشغيل محلي

1. ثبّت Node.js 18 أو أحدث.
2. انسخ `.env.example` إلى ملف جديد اسمه `.env` في مجلد المشروع.
3. أنشئ API key من حساب OpenAI Platform، ثم ضعه في `OPENAI_API_KEY` داخل `.env`. استخدم مفتاحك على الخادم فقط؛ لا ترسله في المحادثات ولا تضعه في HTML أو JavaScript. استخدام الـAPI وفوترته منفصلان عن اشتراك ChatGPT.
4. افتح PowerShell داخل مجلد المشروع وشغّل:

   ```powershell
   node server.js
   ```

5. افتح <http://127.0.0.1:4173/ai-assistant.html>.

لا تفتح صفحة المساعد عبر `file://` أو Live Server وحده؛ يجب تشغيل `server.js` كي يمر طلب النموذج من الخادم.

## ما يستطيع المساعد الوصول إليه

- يرسل المحادثة الحالية، وصورة يختارها المستخدم، ولغة الواجهة والمدينة المختارة إلى OpenAI كي يجيب عنها. لا يرسل بيانات الحساب أو تفاصيل الطلبات.
- عند كتابة رقم طلب أو بريد للبحث، تتم مطابقة الطلبات المحفوظة محليًا في المتصفح ولا تُرسل إلى النموذج.
- يتلقى النموذج كتالوج المنتجات المحدد في `data/ai-products.json` ويعيد معرفات منتجات فقط من هذا الكتالوج؛ تعرض الصفحة المنتج والسعر ورابطه، وزر إضافته للسلة.
- لا يوجد بالمشروع سجل حقيقي لمواقع الفروع أو مخزونها؛ لذلك لا يخترع المساعد متجرًا قريبًا أو توفرًا لحظيًا.

## النشر

الخادم الحالي مناسب للتطوير المحلي. قبل نشره للعموم، استخدم استضافة HTTPS وأضف مصادقة وحدود استخدام ومراقبة للتكلفة وسياسة احتفاظ بالرسائل. لا تجعل مفتاح API متاحًا للمتصفح.
